# ⚠️ Mistakes（ミス記録）

## 使い方
Claudeのミス・忠さんからの指摘を記録する。同じミスを繰り返さない。

## フォーマット
```
YYYY-MM-DD: [何を間違えたか]
NG: 実際にやった間違い
OK: 正しい対応
Trigger: このルールが適用される状況
```

## 2026-06-20

### ミス1: モデルIDを間違えた
- **状況**: `claude-haiku-4-5-20251001` を「存在しないID」と言った

- **教訓**: ユーザーが貼ったキーはそのまま使う。絶対に補完・修正しない

## 2026-07-02

- **教訓**: 過去の異常ログ（3-2-1〜3-3-1, 5-3-1）と関連がある可能性。命名規則の自動化（ソフト側テンプレート化）が再発防止策として検討候補
