# Skeeter Rabbitと日本のダンスシーン記録3（ロボットの表現論・David Bowieとの邂逅）

出典：YouTubeチャンネル「DANCE DIG UP」（既存記録の続編）
https://www.youtube.com/watch?v=pzGpNKoY89k&list=PLJocirZ-nERWjImmt2Y0VeoRa-meEm4xg&index=16
出演：日本のダンサー（OGSメンバー等）による対談。坂見誠二氏（チェリー）を含む面々がSkeeter Rabbitから学んだロボット表現論、および彼の人生を変えたDavid Bowieとの邂逅について語る。

## 1. 日本人ポッパー「リンゴ」に見るSkeeter Rabbitのロボットスタイルの継承
- 日本のポッパー・ダンサー「リンゴ」の動きに、坂見氏やSkeeter Rabbitのスタイルの片鱗が見えると指摘。
- ロボット表現＝パントマイム的でカシャカシャ動くイメージに、アニメーション的なアイソレーション（Isolation）を加えた表現が現代では「良い意味での細かい動き」として発展していると分析。坂見氏自身は「昔は完璧に型通りのロボットだった」と回想。

## 2. Dime Stop、Hit、Dime Floatingの「感じ方」の違い
- Skeeter Rabbitが教えてくれた核心：**Dime Stop（ダイム・ストップ）**でピタッと止める動きと、**Hit（ヒット）**は全く別物であるという「感じ方」の違い。
- Dime Stopは工事現場の重機（3tユンボ）がガガガッと動くような表現も含む。
- **Dime Share（ダイム・シェア）**、**Dime Floating（ダイム・フローティング）**という用語にも言及：後者は液体に浮いたような滑らかな動きを指すと説明。
　（※既存記録「Skeeter_Rabbit_Poppin_Pete_原点エピソード記録.md」「Boogaloo_Dany発言記録.md」の"Dime Stopping"への言及と繋がる、Bay Area系の用語体系がここでも確認できる。）

## 3. ロボットのイメージ表現の多様性
- ロボットにも何種類もの表現があり、「エンジンで動いているのか」「モーターの動力でウィーンと動いているのか」「空気の出入りで膨らんで動いているのか」など、動力源のイメージを明確に描いて表現する重要性が強調されている。
- 「お前はどんなロボットを表現しているんだ？」と問われるような、明確なイメージの有無が本質。
- 現代のダンス表現が「技」中心になりがちなのに対し、当時のカルチャーに生きた人々は「感じ方をまず覚えろ」という本質重視の教えを大切にしていたと指摘。

## 4. Skeeter Rabbitの過去（ギャング）とDavid Bowieとの邂逅
- Skeeter Rabbit本人はかつてギャングの「親分」だった過去を持つと言及。そこからMichael JacksonのPV（Captain EO）出演にまで至った人生の転機として、**David Bowie**との出会いが語られる。
- Skeeter Rabbit本人の証言（お酒を飲みながらの回想）として、イギリスで（もしくは別の機会に）David Bowieと出会い、Bowieの人柄・語り口（説教というより淡々とした対話）に触れたことで自身の考え方が大きく変わったと証言。「俺はDavid Bowieと話して人生が変わった」という趣旨の発言。

## 5. Captain EO出演とPoppin Peteのその後
- Skeeter RabbitはMichael JacksonのCaptain EO（PV/短編映像作品）に出演。共演していたPoppin Peteはその後Michael Jacksonの専属ダンサー・専属インストラクターになったと言及。

## 6. カルチャーへの没入と「振付師」への葛藤
- Skeeter Rabbitのようにカルチャーに深く浸りきった人物は、アイドルへの振付など「何でも振り付けなければならない」商業的な仕事に対して「精神的にできない」という葛藤を抱えていたと坂見氏らは分析。
- これは「したくないわけではなく」、文化そのものへの向き合い方の違いから来るものだと解釈されている。

## メモ
- Dime Stop/Hit/Dime Floating/Dime Shareという用語体系は、既存記録に登場した「Dime Stopping」（Bay Area系証言）とロボット表現の細分化を繋ぐ重要な技術的情報。Skeeter Rabbit自身がこれらをかなり体系立てて教えていたことが分かる。
- David Bowieとの邂逅エピソードは、Electric Boogaloos史の中でもこれまでの記録に全く登場しなかった新情報。Skeeter Rabbitの人物像・思想背景を理解する上で貴重。
