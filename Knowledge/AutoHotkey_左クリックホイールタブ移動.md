# AutoHotkey：左クリック＋ホイールでタブ移動（W10Wheel共存版）

## 概要
W10Wheel（右クリック＋トラックボール移動でスクロール）と競合しないよう、AutoHotkeyのタブ切り替えショートカットを「左クリック＋ホイール」に割り当てた設定。**動作確認済み・現在運用中。**

## 経緯・設計判断
- 右クリックをトリガーにすると、W10Wheelの「右クリック＋移動→スクロール変換」と衝突し、通常スクロール時に誤ってタブが切り替わってしまう問題があった。
- サイドボタン案なども検討したが、最終的に「左クリック（LButton）」をトリガーにすることで、W10Wheelの右クリック系動作と完全に分離し解決。
- 「タブ移動直後にもう一度ホイールを回すと1個ずれる」現象があったため、左ボタンを離した瞬間にCtrlキーを強制的にUpさせるリセット処理を追加して解消。

## 完成版スクリプト（AutoHotkey v2）

```ahk
#Requires AutoHotkey v2.0

; 左ボタン＋ホイールでタブ切り替え
~LButton & WheelUp::Send "^{PgUp}"
~LButton & WheelDown::Send "^{PgDn}"

; 左ボタンを離した瞬間に、修飾キー（Ctrlなど）の状態を強制リセットする
~LButton Up::
{
    ; Ctrlキーが物理的に離れているのにシステムが「押しっぱなし」と誤解するのを防ぐ
    Send "{Ctrl Up}"
}
```

## 操作方法
- 左ボタンを押しながらホイールを回す → タブ移動（Ctrl+PageUp/PageDown）
- 左ボタンのみ／左ボタン+ドラッグ → 通常のクリック・ドラッグとして動作（`~`により素通し）
- W10Wheel（右クリック＋トラックボール移動）とは完全に独立して動作し、競合しない
