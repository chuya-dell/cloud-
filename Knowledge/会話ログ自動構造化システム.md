# 会話ログ→Obsidian自動構造化システム

**作成日**: 2026-06-20

## 概要
Claude Codeの会話ログをPC起動時に自動でObsidianに構造化保存するシステム。

## ファイル構成
```
G:\マイドライブ\1.実験データ_gdrive\claud.セッション\
├── save_all_sessions.py          # ログ収集（既存）
├── process_logs_to_obsidian.py   # 構造化・Obsidian書き込み
├── config.env                    # APIキー（Anthropic）
├── processed_logs.json           # 処理済みファイル管理
├── run_process_logs.bat          # 実行バッチ
└── register_task.ps1             # タスクスケジューラ登録用
```

## 処理フロー
1. PC起動・ログオン → 30秒後に自動実行（タスク名: ProcessLogsToObsidian）
2. `save_all_sessions.py` で `~\.claude\projects\` 以下の .jsonl を `AI会話ログ\` に .md として保存
3. `process_logs_to_obsidian.py` が未処理ファイルを検出
4. Anthropic API（claude-haiku-4-5-20251001）に会話ログを送り構造化JSON取得
5. Obsidianに書き込み：
   - `Daily/YYYY-MM-DD.md` に追記
   - `Knowledge/` に技術知識ファイル生成
   - `Decision/` に決定事項ファイル生成

## 使用ライブラリ
```
pip install anthropic json-repair
```

## APIについて
- **Anthropic API**（claude-haiku-4-5-20251001）を使用
- 従量課金（プリペイド）、$5チャージで数年分
- キーは `config.env` に保存、バッチが起動時に環境変数に読み込む

## Gemini APIが使えない理由
Google AI Pro契約ユーザーは無料APIティアが `limit: 0` になる。
支払い情報を登録すれば使えるが、Anthropicの方がシンプル。

## 別PCでの設定手順
1. `config.env` をコピーしてAPIキーを設定
2. `register_task.ps1` を管理者PowerShellで実行
3. 必要ライブラリをインストール: `pip install anthropic json-repair`
