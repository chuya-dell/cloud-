## Claude Desktop Dispatch機能のセットアップ手順

### 概要
Claude Desktopの「Dispatch機能」はスマートフォンのClaude モバイルアプリからPC上のClaude Desktopを操作する連携機能です。

### セットアップ手順

#### 1. PC側でDispatchを有効化する
- Claude Desktopを開く
- 左下または右上のアカウントアイコン/プロフィール画像をクリック
- またはハンバーガーメニュー（≡）をクリック
- 「Settings」または「設定」を選択
- 「Dispatch」「Phone」「Mobile」というセクションを探す
- Dispatchを有効化するトグルをオンにする

#### 2. アカウント確認
- PC側のClaude Desktopが同一のGoogleアカウント（例: chuya2816@gmail.com）でサインインしていることを確認

#### 3. 環境確認
- Claude Desktopが起動していることを確認
- 最新バージョンにアップデートされているか確認
  - メニュー → Help → Check for Updates

### よくある失敗原因
- PC側でDispatch設定がオフになっている
- PCとスマホが同じWi-Fiネットワークに接続されていない（必要な場合）
- Claude Desktopのバージョンが古い
- 異なるアカウントでサインインしている
