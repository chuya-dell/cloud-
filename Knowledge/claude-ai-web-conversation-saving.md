## claude.ai Web からの会話保存方法

### 概要
claude.ai Web/モバイルアプリからは自動保存の仕組みがないため、手動トリガー方式またはChrome拡張機能による実装が必要。

### 方式1: 手動トリガー（推奨・現実的）

**方法:**
会話の最後に以下のような指示をClaudeに送る
```
「この会話をObsidianに保存して」
「セッションを G:\マイドライブ\AI会話ログ\claude-web_[日時].md として保存してください」
```

**理由:**
- claude.aiはMCP（Model Context Protocol）に対応
- `obsidian-vault` MCPが設定済みであれば、ClaudeがVaultに直接書き込み可能
- 実装が簡単で確実

**注意点:**
- 毎回手動で「保存して」と言う必要がある
- 完全自動ではないが、数秒で保存完了

### 方式2: Chrome拡張機能（未実装・高度）

**方法:**
Claude AIのページを監視し、会話ツリーが更新されたら自動でファイル化する拡張機能を開発。

**難易度:**
- 開発難易度: 高
- 実装時間: 数時間
- 技術: Chrome Extensions API, content script, background service worker

**メリット:**
- Web側でも完全自動保存
- Obsidianファイルとして自動整形

**デメリット:**
- カスタム開発が必要
- claude.aiの仕様変更に依存
- メンテナンスコストが高い

### 推奨運用方針

1. **当面:** 手動トリガー方式で運用（全プラットフォーム統一）
2. **将来:** 不便さが目立つようなら拡張機能開発を検討
3. **代替案:** Make/Zapierなどの自動化サービスは、claude.aiのWebhook非対応により限定的
