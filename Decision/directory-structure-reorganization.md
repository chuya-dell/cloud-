## マイドライブ内のClaude関連ファイルディレクトリ統一化

**決定日**: 2026-06-20

**理由**: 
マイドライブ直下に散在していたClaude関連のフォルダ（セッション、AI会話ログ）を一箇所に統合し、管理の効率化と整理を図るため。

**内容**: 

### 新ディレクトリ構成
```
G:\マイドライブ\n└── Claude/
    ├── セッション/           ← 旧: 1.実験データ_gdrive\claud.セッション
    └── AI会話ログ/          ← 旧: マイドライブ直下の AI会話ログ
```

### 実施内容
1. `G:\マイドライブ\Claude\セッション\` にセッションファイル移動
2. `G:\マイドライブ\Claude\AI会話ログ\` に会話ログ移動
3. Claude Code のプロジェクト設定・memory を新パスにコピー
4. 旧フォルダ削除予定（`1.実験データ_gdrive\claud.セッション`）

### 除外
`antigravity_chat_logs` はClaude関連としてまとめない（独立したフォルダとして保持）

- Claude Code の作業ディレクトリ
