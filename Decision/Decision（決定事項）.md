## 2026-06-20 Zotero論文の参照方針
- 論文参照は**Abstractと書誌情報（著者・年・雑誌・DOI）に限定**
- 本文PDF・メモ・ハイライトはObsidian経由では参照不可
- 「〇〇について調べて」→ キーワード検索で関連論文を抽出、詳細はZotero本体/PDFリーダーへ
- 全件読込はトークンコスト大のため非効率→ 必要な論文のみ抽出する運用

## MCP Obsidian Vault 接続問題の対処方針（2026-06-21）

**手順:**
1. Claude Code デスクトップアプリをタスクトレイからも含めて完全終了 → 再起動
2. 再起動後に MCP 接続状態を確認
3. 接続が復帰しない場合、設定 → MCP Servers → `obsidian-vault` 横の再起動ボタン
4. Google Drive ストリーミングフォルダのアクセス遅延が原因の可能性がある場合は別パスへの移動を検討
