# システム設計の決定事項（2026-06-20）

## 基本方針
- データはGoogle Drive / Obsidian Vaultに集約する
- AIはどれが消えてもデータは残る設計
- ファイル形式は.md（どのAIでも読める）

## 採用した構成
- Claude Code → Obsidian Vault（MCP/server-filesystem）
- Gemini → Google Drive（アプリ連携）
- 両AIがDriveを共有記憶として使う

## トークン管理方針
- セッション開始時はINDEX.mdのみ読む
- 必要なファイルだけピンポイントで取得
- 会話が長くなったら /clear → Obsidianから再開

## 却下した方針
- Gemini会話の完全自動保存 → 技術的に不可能
- 起動時のタスクスケジューラ → PCが重くなるため却下
- 夜12時の定期保存 → シャットダウンしているため却下
