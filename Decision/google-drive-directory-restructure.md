## Google Drive内のClaude関連ファイル統合

**決定日**: 2026-06-20

**理由**: マイドライブ内に散在していたClaude関連フォルダを一元管理し、作業効率を向上させるため

**内容**: 
```
構成前:
G:\マイドライブ
├── 1.実験データ_gdrive
│   └── claud.セッション
├── AI会話ログ
└── antigravity_chat_logs

構成後:
G:\マイドライブ
├── Claude/
│   ├── セッション/（claud.セッション を移動）
│   └── AI会話ログ/（AI会話ログ を移動）
├── 1.実験データ_gdrive（セッション削除後）
└── antigravity_chat_logs（変更なし）
```

**影響範囲**:
- Claude Code プロジェクト設定のディレクトリパス更新が必須
- 既存セッション参照パスの更新
- AI会話ログの保存先パスの更新
