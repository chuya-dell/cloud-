# 運用設計確定（2026-06-21）

## 基本方針
- **Obsidian = メインデータバンク**（正のデータ・常に最新）
- **Notion = 常に同じものを持つミラー**（削除しない・Obsidian追加済みチェックあり）
- どちらも削除せず常に同期された状態を保つ

## データ管理の役割分担

| データ | Obsidian | Notion |
|---|---|---|
| タスク | Projects/に蓄積 | 📋タスク管理DB（Obsidian✅チェック付き） |
| 会話ログ | Daily/に記録 | 📅 Daily ログ |
| 知識・解決法 | Knowledge/に記録 | 💡 Knowledge |
| 決定事項 | Decision/に記録 | 📌 Decision |
| ミス記録 | Mistakes/ミス記録.md | ⚠️ Mistakes |
| プロジェクトログ | Projects/に記録 | 🔬 Projects |
| 論文（Zotero） | Zotero/（373件） | 📚 論文DB（Obsidian✅チェック付き） |
| Claude会話ログ | Daily/に転記 | 📝 Claude会話ログ（一時保管→転記後も残す） |
| Claudeの記憶 | Preferences/profile.md | 🧠 Claudeの記憶 |

## Obsidian✅チェックの運用
- NotionのタスクDB・論文DBに「Obsidian✅」チェックボックスあり
- Claude CodeがObsidianに書き込んだらNotionの該当項目にチェックを入れる
- チェックなし = まだObsidianに未反映

## claude.aiの運用ルール
1. 「記録して」→ Notionの「📝 Claude会話ログ（一時保管）」に追記
   - URL: https://app.notion.com/p/386e390406d181a298eef4243ce1e267
2. PC前でClaude Code起動時 → Notionの内容をObsidianにも転記（削除しない）

## タスクのライフサイクル
```
タスク登録 → Claudeが見積時間を推定・NotionとObsidian両方に記録
　↓
完了時 → 「〇〇終わった、△時間かかった」と申告
　↓
Notionの実績時間(h)を更新・Obsidian✅にチェック
　↓
ObsidianのProjects/にも転記
```

## 優先度の定義
| 記号 | 意味 |
|---|---|
| 🔴 高 | 締切あり・直近で着手必須 |
| 🟡 中 | 締切ないが研究・仕事に直結 |
| 🟢 低 | 直結しない・後回し可能 |
| ⚪ 保留 | 判断不要・アイデア段階 |
