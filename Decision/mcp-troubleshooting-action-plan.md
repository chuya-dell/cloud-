## MCP Obsidian Vault 接続問題の対処方針

**決定日**: 2026-06-21

**理由**: MCP obsidian-vault サーバーが切断されており、Claude Code デスクトップアプリ側の接続確立に問題がある。フォルダアクセスとサーバープロセスは正常だが、初期化タイミングに問題がある可能性が高い。

**内容**: 
1. Claude Code デスクトップアプリを完全に終了して再起動（タスクトレイから完全終了）
2. 再起動後、MCPサーバーの手動リロード機能を試行
3. 上記で解決しない場合、Google Drive ストリーミングフォルダの遅延を疑い、別パスへの移動を検討

**影響範囲**: Obsidian Vault への読み書き機能全般
