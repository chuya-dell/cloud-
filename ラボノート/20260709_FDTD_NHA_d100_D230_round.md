# FDTD NHA d100 D230 丸みホール スクリプト開発

## 概要

金ナノホールアレイ（NHA）のFDTDシミュレーション用スクリプトを開発。
ホールの上下エッジに丸みをもたせた形状を Analysis Group Setup Script で実装した。

- 格子定数: a = 460 nm（六方格子）
- ホール径: D = 230 nm
- 金膜厚さ: depth = 100 nm

### NHA_d100_D230_round-1.lsf
- 元スクリプト（pillar_analyzerの記録から復元）
- 上下対称・内向き丸み、r = 15 nm
- FDTD完全版（光源・モニター・run・スペクトル出力付き）
- Script File として直接実行

### NHA_d100_D230_round-2.lsf
- Analysis Group Setup Script 版（形状確認・パラメーター調整用）
- 7個六方クラスター（中心1個＋60°間隔6個）、空気ホールのみ
- 非対称丸み: 上面=外向きフレア、下面=内向きテーパー、r = 40 nm
- Variables タブから GUI でパラメーター変更可能

## 形状の実装方針

### 丸みの近似方法
空気ホールを N 枚の円板スライスで近似。各スライスの半径を四分円プロファイルに従わせる。

**上面（外向きフレア）**:
- t = (i-0.5)/N、z_c = depth/2 - r_top + r_top*t
- r_air = (r_hole + r_top) - sqrt(r_top² - (r_top*t)²)
- t=0 で r_air = r_hole、t=1 で r_air = r_hole + r_top（上面で最大）

**下面（内向きテーパー）**:
- z_c = -depth/2 + r_bot - r_bot*t
- r_air = (r_hole - r_bot) + sqrt(r_bot² - (r_bot*t)²)
- t=0 で r_air = r_hole、t=1 で r_air = r_hole - r_bot（下面で最小）

### オブジェクト優先度
Lumericalはオブジェクトツリーの**下**が**高優先度**（後に追加したものが優先）。
mesh order 数値ではなく追加順序で制御する。

## Lumerical スクリプト作法（ハマりポイント）

| 問題 | 原因 | 解決 |
|---|---|---|
| `addfdtd` エラー | Analysis Group 内では使用不可 | グループ外で手動追加 |
| `switchtolayout` エラー | セットアップスクリプト文脈では使用不可 | `deleteall` のみ使用 |
| `function` 構文エラー | セットアップスクリプトで関数定義不可 | インライン展開 |
| `max(a,b)` エラー | スカラー2引数の max は未対応 | `if (val<0){val=0;}` で代替 |
| `h` が予約語 | Planck 定数として定義済み | ループ変数を `k` に変更 |
| `hx(i)=` 代入エラー | 配列は `()` で代入不可 | `hx = [0, a, ...]` で定義 |
| `adduserprop` 重複警告 | 2回目以降に既存プロパティ検出 | Warning は無害 |
| `get("a")` エラー | オブジェクトプロパティ用、ユーザープロパティには使えない | `getnamed("::model","a")` を使う |

## スクリプト全文

### NHA_d100_D230_round-2.lsf（Analysis Group 用）

```lsf
# ============================================================
# Gold Nanohole Array - Air holes only (Analysis Group Setup Script)
# 7-hole hexagonal cluster: 1 center + 6 surrounding at 60deg
# ============================================================

# --- Initialize parameters in Variables tab ---
adduserprop("a",      0, 460e-9);
adduserprop("D",      0, 230e-9);
adduserprop("depth",  0, 100e-9);
adduserprop("r_top",  0, 40e-9);
adduserprop("r_bot",  0, 40e-9);
adduserprop("N",      0, 32);
adduserprop("n_hole", 0, 1.0);

# --- Read parameters ---
a      = getnamed("::model", "a");
D      = getnamed("::model", "D");
depth  = getnamed("::model", "depth");
r_top  = getnamed("::model", "r_top");
r_bot  = getnamed("::model", "r_bot");
N      = getnamed("::model", "N");
n_hole = getnamed("::model", "n_hole");

r_hole = D / 2;

deleteall;

# Hole positions: center + 6 surrounding at 60deg
hx = [ 0,  a,  a/2, -a/2, -a, -a/2,  a/2];
hy = [ 0,  0,  a*sqrt(3)/2,  a*sqrt(3)/2,  0, -a*sqrt(3)/2, -a*sqrt(3)/2];

for (k = 1; k <= 7; k = k + 1) {

    addcircle;
    set("name", "air_" + num2str(k));
    set("x", hx(k));  set("y", hy(k));
    set("radius", r_hole);
    set("z min", -depth/2 + r_bot);  set("z max", depth/2 - r_top);
    set("material", "<Object defined dielectric>");
    set("index", n_hole);

    # Top rounding: outward flare
    for (i = 1; i <= N; i = i + 1) {
        t     = (i - 0.5) / N;
        z_c   = depth/2 - r_top + r_top*t;
        dz    = r_top / N;
        val   = r_top*r_top - (r_top*t)*(r_top*t);
        if (val < 0) { val = 0; }
        r_air = (r_hole + r_top) - sqrt(val);
        addcircle;
        set("name", "top_" + num2str(k) + "_" + num2str(i));
        set("x", hx(k));  set("y", hy(k));
        set("radius", r_air);
        set("z min", z_c - dz/2);  set("z max", z_c + dz/2);
        set("material", "<Object defined dielectric>");
        set("index", n_hole);
    }

    # Bottom rounding: inward taper
    for (i = 1; i <= N; i = i + 1) {
        t     = (i - 0.5) / N;
        z_c   = -depth/2 + r_bot - r_bot*t;
        dz    = r_bot / N;
        val   = r_bot*r_bot - (r_bot*t)*(r_bot*t);
        if (val < 0) { val = 0; }
        r_air = (r_hole - r_bot) + sqrt(val);
        addcircle;
        set("name", "bot_" + num2str(k) + "_" + num2str(i));
        set("x", hx(k));  set("y", hy(k));
        set("radius", r_air);
        set("z min", z_c - dz/2);  set("z max", z_c + dz/2);
        set("material", "<Object defined dielectric>");
        set("index", n_hole);
    }
}
```
