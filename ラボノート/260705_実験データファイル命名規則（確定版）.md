# 実験データファイル命名規則（確定版）

## summary

実験データのフォルダ名・ファイル名の命名規則を確定。日付はフォルダ名にのみ含め、個々のファイル名には含めない。

## rule

- **フォルダ名**: `YYMMDD_実験内容の説明`（YYMMDDは6桁の年月日）
  - 例: `260704_sam位置合わせtest`
- **ファイル名**: `条件-セット-連番`のみ（日付を含めない）

## note

- 過去の一部ノート（例: 260704_p200デザインナイフ位置合わせ検証.md）ではフォルダ名の区切りが「260704 sam 位置合わせ test」のようにアンダースコアなし表記になっていたが、正式には`_`区切りの`YYMMDD_実験内容の説明`が正しい
- 今後の実験ノート作成時はこの規則を参照すること
