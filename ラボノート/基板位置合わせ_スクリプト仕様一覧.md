## Claude Code版（PC-alignment-claude）

### `register_images.py`
**役割**：基準画像と対象画像のスクラッチ位置・角度を検出し、画像全体を回転・平行移動補正してTIFF保存する単一スクリプト。

**処理フロー**
1. `detect_scratch_angle`：列範囲(30,250)内で各行の最暗点を抽出し線形回帰→縦線の傾き（度）を算出
2. `detect_scratch_col` / `detect_scratch_row`：列・行の平均輝度最小位置からスクラッチ座標(col, row)を検出
3. 基準画像との角度差から回転補正（`cv2.warpAffine`、`getRotationMatrix2D`）
4. 回転後画像で再度スクラッチ位置検出→基準との差分(dx, dy)で平行移動補正
5. 結果TIFFを`registered/`フォルダに保存、補正量をコンソール出力

**設定（コード内ハードコード、要編集）**
```python
INPUT_DIR = Path(r"G:\マイドライブ\1.実験データ_gdrive\5.生データ D\260630 dna sam\位置合わせ")
OUTPUT_DIR = INPUT_DIR / "registered"
REFERENCE = "1-0.tif"
TARGETS = ["1-1.tif", "1-2.tif", "1-3.tif"]
SCRATCH_COL_RANGE = (30, 250)
```

**使い方**：上記定数を編集後、`python register_images.py` を直接実行（CLI引数なし）。

**既知の注意点**
- 出力時 `np.clip(img_final, 0, 255).astype(np.uint8)` としており、元画像が16bit TIFFの場合は階調情報が失われる可能性がある（要確認）。
- 外れ値除去なし。スクラッチ範囲内に他の暗い構造があると角度推定が歪むリスクあり。

**保存場所（入出力）**
- 入力：`G:\マイドライブ\1.実験データ_gdrive\5.生データ D\260630 dna sam\位置合わせ\` 内の `1-0.tif`〜`1-3.tif`
- 出力：同フォルダ内 `registered\*_registered.tif`

## Antigravity版（PC-alignment-anti）— 採用パイプライン

### 全体構成（2系統のパイプラインが存在）

**系統A：位置合わせ評価パイプライン（実データ用、今回の検証で使用）**
```
analyzer.py（各画像のピラー検出）→ {name}_pillars.csv
   ↓
run_alignment_pipeline.py（registration.pyを呼び出し2段階アライメント実行）→ {name}_aligned_to_1-0.csv
```

**系統B：汎用解析パイプライン（1枚の画像を解析・可視化・集計まで一括実行する統合版）**
```
run_pipeline.py
  ├─ analyzer.py（解析）
  ├─ visualize.py（検出位置の重ね合わせ画像生成）
  └─ summarize.py（ヒストグラム・空間ヒートマップ・統計サマリー）
```
位置合わせ（registration.py）は系統Bには組み込まれていない。系統Bは単一画像の検出・可視化・統計が目的。

**系統C：検出精度の自己検証（合成データ）**
```
generate_test_image.py（既知座標の合成画像生成）→ synthetic_pillars.png + ground_truth.csv
   ↓
analyzer.py（同じ合成画像を解析）→ results.csv
   ↓
evaluate.py（ground_truthとresultsをKDTreeで突合、Precision/Recall/F1・輝度誤差を算出）
```

### `analyzer.py`
**役割**：暗視野/明視野顕微鏡画像からピラー（プラズモン結晶構造）を検出し、座標・強度をCSV化する。

**処理フロー**
1. `cv2.imdecode(np.fromfile(...))` で日本語パス対応の画像読み込み（グレースケール）
2. 画像をタイル分割（デフォルト2000px、overlap 50px）して処理（大判画像対応）
3. 各タイルでモルフォロジー Top-Hat フィルタによる背景除去→ガウシアンブラーでノイズ低減
4. 検出方式2種類：
   - `blob`法：Otsu二値化→Connected Componentsでブロブ検出、面積でフィルタ（`min_area`/`max_area`）
   - `peak`法：膨張処理による局所最大値検出＋3×3窓でサブピクセル重心計算（HCP密構造向け、デフォルトはこちら（`run_pipeline.py`側）)
5. タイル境界の重複検出を排除（`tile_bounds`によるユニーク領域判定）
6. `peak`法選択時は近接ピーク剪定（`prune_close_peaks`、KDTreeで近接ペア検出）
7. 結果を`pillar_id`付きDataFrameとしてCSV出力

**使い方（CLI、単独実行時）**
```bash
python analyzer.py --image <path_to_tif> --output <output_csv> \
  --tile-size 2000 --overlap 50 --min-area 3 --max-area 100 \
  --top-hat 15 --method blob --min-dist 5 --invert
```
- `--method peak`：HCP格子のような密な構造に適する
- `--invert`：明視野（明るい背景に黒いピラー）画像向け

**保存場所（デフォルト出力）**
`C:/Users/chuya/.gemini/antigravity/scratch/plasmon_analyzer/results.csv`（`--output`で変更可）

### `registration.py`
**役割**：2段階（粗位置合わせ＋ICP）でピラー点群を位置合わせするコアモジュール。単体では実行せず`run_alignment_pipeline.py`等からimportして使用。

主要関数：
- `load_image_unicode`：日本語パス対応画像読み込み
- `detect_grooves`：縦・横スクラッチ溝の検出（プロファイル最小値、移動平均窓15で平滑化）
- `calculate_coarse_shift`：基準・対象画像間の溝座標差からStage1の並進量(dx, dy)算出
- `fine_alignment_icp`：KDTree最近傍探索＋SVDによる剛体変換推定を反復（Stage2、外れ値除去`max_match_dist=3.0`、収束判定`tolerance=1e-6`）
- `align_and_match_dataframes`：上記を統合し、対象点群を最終座標に変換、`matched_ref_id`・`alignment_distance`列を付与して返す（メインAPI）

### `run_alignment_pipeline.py`
**役割**：基準・対象のピラーCSVを読み込み、`registration.align_and_match_dataframes`を実行してアライメント結果を保存・品質評価するバッチ実行スクリプト（前回記録した評価結果はこのスクリプトの出力）。

**処理フロー**
1. 基準ピラーCSV（`1-0_pillars.csv`）読み込み（事前に`analyzer.py`実行が必要）
2. ターゲット（1-1, 1-2, 1-3）ごとに2段階アライメント実行
3. アライメント結果CSV保存：`{name}_aligned_to_1-0.csv`
4. 品質評価を出力：マッチ率（距離≤1.5px）、RMSE、平均距離、中央値距離、最大距離、サブピクセル精度内割合（距離<0.5px）

**使い方**：パス（`raw_folder`, `outputs_dir`）はコード内ハードコード。`python run_alignment_pipeline.py`で実行。事前に各画像に対し`analyzer.py`でピラーCSVを生成しておく必要がある。

**保存場所**
- 入力画像：`G:/マイドライブ/1.実験データ_gdrive/5.生データ D/260630 dna sam/位置合わせ/`
- 入力ピラーCSV・出力アライメント結果：`C:/Users/chuya/.gemini/antigravity/scratch/plasmon_analyzer/test_outputs/`

### `run_pipeline.py`
**役割**：1つの実験フォルダ内の画像1枚に対し「解析→重ね合わせ可視化→統計サマリー」を一括実行するオーケストレーター。フォルダ内に画像が1つだけなら自動検出、複数あればフォルダ名と一致するものを使用（それでも複数あればエラーで`--image`指定を要求）。

**使い方（CLI）**
```bash
python run_pipeline.py --dir <experiment_folder> [--image <filename>] \
  --method peak --min-dist 4 --min-area 3 --max-area 100 --top-hat 15 \
  --radius 1 --thickness -1 --crop-size 800 --size 1.0
```
（`--method`のデフォルトはこちらでは`peak`。`analyzer.py`単独実行時のデフォルト`blob`と異なる点に注意）

**保存場所**：`--dir`で指定したフォルダ内に `{image_name}_results.csv` / `_overlay.png` / `_histogram.png` / `_heatmap.png` を出力。

### `visualize.py`
**役割**：検出結果CSVの座標を元画像上に赤丸でプロットし、重ね合わせ画像（オーバーレイ）を生成。中央部分をクロップして保存するオプションあり（目視確認用）。

**使い方（CLI、単独実行時）**
```bash
python visualize.py --image <path> --csv results.csv --output overlay_crop.png --crop --crop-size 800 --radius 2 --thickness -1
```

### `summarize.py`
**役割**：検出結果CSVから統計量（検出数、輝度の平均・標準偏差・最小最大）をコンソール出力し、輝度ヒストグラムと空間ヒートマップ（座標×輝度の散布図、`inferno`カラーマップ）をPNG保存。

**使い方（CLI、単独実行時）**
```bash
python summarize.py --csv results.csv --hist intensity_histogram.png --map intensity_heatmap.png --size 0.3
```

**使い方**：引数なし、`python generate_test_image.py`で直接実行。

### `evaluate.py`
**役割**：`generate_test_image.py`が作った正解座標(ground_truth.csv)と`analyzer.py`の検出結果(results.csv)をKDTreeで突合し、検出精度を定量評価する。

**評価指標**
- Precision（適合率）、Recall（再現率）、F1スコア（マッチ距離閾値3.0px）
- 座標誤差（平均・最大、ピクセル単位）
- 輝度誤差（真値 vs 検出値の平均強度・3×3box強度、MAE/RMSE、相関係数R）
- `create_visual_verification`：指定領域（デフォルト2000,2000を起点に300×300px）をクロップし、正解位置を緑点、検出位置を赤丸で重ね描画したPNGを保存（目視検証用）

**使い方**：引数なし、`python evaluate.py`で直接実行（パスはコード内ハードコード、`generate_test_image.py`の出力を前提）。
**保存場所**：可視化画像 `C:/Users/chuya/.gemini/antigravity/brain/791c8f54-1705-4b80-864f-cb0af0737e3d/detection_overlay.png`

## 注意：保存先パスがコード間で不統一

Antigravity版内でも出力先ディレクトリの取り扱いがファイルごとに異なる：
- `analyzer.py`単独実行時のデフォルト出力：`.../plasmon_analyzer/results.csv`
- `run_pipeline.py`経由の出力：`--dir`で指定した実験フォルダ内（ファイル名に画像名プレフィックス付き）
- `run_alignment_pipeline.py`の出力：`.../plasmon_analyzer/test_outputs/`
- `evaluate.py`の可視化画像：`.../antigravity/brain/791c8f54-.../`（UUID付きのAntigravity内部スクラッチ領域）

実運用では`run_alignment_pipeline.py`系統（系統A）を使うことになるため影響は限定的だが、フォルダ構成を統一したい場合は要整理。
