# AI外部脳 Vault へようこそ

このVaultはObsidianをAIと連携した「第二の脳（外部脳）」として活用するためのシステムです。

---

## フォルダ構造

| フォルダ | 用途 |
|---------|------|
| 📥 `Inbox/` | キャプチャした情報を一時保管。後で整理する |
| 📝 `Notes/Permanent/` | 自分の言葉で書いた恒久的なアイデアノート（Zettelkasten） |
| 📚 `Notes/Literature/` | 書籍・記事・動画などの参照ノート |
| 🗂 `Projects/` | 進行中のプロジェクト |
| 🔗 `Resources/` | テーマ別のリファレンス集 |
| 📅 `Daily/` | デイリーノート（振り返り・タスク管理） |
| 📋 `Templates/` | ノートテンプレート |
| 🗃 `Archive/` | 完了・不要になったノートの保管庫 |

---

## AIとの連携

このVaultでは以下のObsidianプラグインでAI機能を活用します：

- **Text Generator** — ノートの文章生成・要約・アイデア展開
- **Smart Connections** — ノート間の意味的なつながりをAIで発見
- **Obsidian Git** — GitHubへの自動同期

---

## 使い方フロー

```
1. 気になった情報 → Inbox/ に素早くキャプチャ
2. Inbox を定期的にレビュー → Notes/Permanent/ や Notes/Literature/ へ整理
3. AI（Text Generator）でアイデアを展開・要約
4. Smart Connections でノート間のつながりを発見
5. Daily/ で毎日の振り返りと次のアクションを記録
```
