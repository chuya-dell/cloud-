# ピラー上部選択的固定化プロトコル

tags: #実験プロトコル #DNA固定化 #コンタクト転写 #APTES

---

## 方針

**乾式コンタクト転写**でピラー先端にチオール修飾DNAを選択的に固定化する。

### 機構
- ドナー（APTESガラス）の表面官能基 = **-NH₂**（アミノシラン基）
- DNA保持の駆動力 = **-NH₂⁺ ↔ DNA-PO₄⁻** 静電相互作用（弱い・可逆）
- 転写の駆動力 = **Au-S 共有結合**（~40 kcal/mol）（強い・不可逆）
- この結合エネルギー差が選択的転写を成立させる

---

## ドナー基材の選択

### 採用：APTESガラス（条件A）＋ COP平板（条件B）
### 不採用：シリコーンゴム → サイドウォール非特異転写リスクあり

| 項目 | APTESガラス | COP平板 |
|------|------------|---------|
| APTES修飾 | ✅ シラノール基豊富・確立済み | ⚠️ O₂プラズマ+APTES必要 |
| 平坦性 | ✅ 光学研磨品 | ✅ 射出成形品 |
| 根拠の厚さ | ◎ 文献豊富 | △ 条件検討要 |
| 用途 | 基準条件 | デバイス基材との親和性確認 |

---

## レシピ（APTESガラス版）

### 必要試薬・器具
- スライドガラス
- APTES（3-aminopropyltriethoxysilane）、エタノール、アセトン、超純水、N₂
- チオール修飾ssDNA（5'末端 -SH、DTT不含）、TEバッファー
- 相補鎖ssDNA、TEバッファー
- 平坦Au基板（蒸着Au/ガラス）、錘（均一荷重用）
- 蓋付きプラスチックケース、キムワイプ
- シリコーンゴムシート（ウェル作製用、直径1〜1.5 cm）
- ソニケーター

---

### Step 0：スライドガラス洗浄

```
アセトンでソニケーション 10分
→ EtOHですすぎ
→ 超純水ですすぎ
```

---

### Step 1：活性化

```
UV/O₃クリーナー 20分 または O₂プラズマ 100W / 0.2 mbar O₂ / 60秒
→ 超純水ですすぎ
→ N₂乾燥
→ 30分以内にStep 2へ（活性化は経時劣化）
```

---

### Step 2：APTES修飾（液相法）

```
APTES修飾液 200 µL を調製
（APTES 4 µL + EtOH 190 µL + 超純水 6 µL）
→ シリコーンウェルに入れて10分浸漬（室温）
→ EtOH 200 µL × 3回洗浄
→ N₂乾燥
→ 110°C 1時間キュア（シラン架橋を完結させる）
```

**根拠：**
- Apte et al., *Biosensors* 2023, 13, 36（OA）
  https://www.mdpi.com/2079-6374/13/1/36

---

### Step 3：チオールDNA調製

```
チオール修飾ssDNA（DTT不含）をTEで1 µMに希釈
→ 50 µL調製
```

> 条件検討：0.1 / 1 / 10 µM

---

### Step 4：DNAをドナーに担持

```
DNA溶液（1 µM）50 µL をシリコーンウェル内に滴下
→ 蓋付きプラスチックケース内（濡れキムワイプで湿度保持）、室温30分インキュベート
→ 自然乾燥（室温5〜10分）
```

---

### Step 5：乾式コンタクト転写

```
Au基板をドナー（DNA担持ガラス）の上にフェイスダウンで静置
→ 錘で均一荷重（初回：200 g）、室温2分接触
→ Au基板をゆっくり剥離
```

> 荷重・接触時間は転写確認後に条件検討

---

### Step 6：洗浄

```
TE 200 µL に5分浸漬
→ TE 200 µL × 3回洗浄
```

---

### Step 7：転写確認

```
① 暗視野顕微鏡 + sCMOSでベースライン測定
② 相補鎖（1 µM）50 µL をハイブリ 1時間
③ TE 200 µL × 3回洗浄
④ 再測定
① → ④ の散乱光変化を確認 → 変化あり = 転写成功
```

## レシピ（COP版）

### ガラス版との差分のみ。Step 3〜7は同じ。

### 必要試薬・器具（追加分）
- COP平板（ラボ在庫品）
- O₂プラズマ装置（必須）

---

### Step 0：COP洗浄

```
アセトンでソニケーション 10分
→ EtOHですすぎ
→ 超純水ですすぎ
```

---

### Step 1：COP活性化

> ⚠️ COPは疎水性のためUV/O₃では活性化不十分。O₂プラズマ必須。

```
O₂プラズマ：50〜100 W / 0.2 mbar O₂ / 30秒
→ 5分以内にStep 2へ（疎水回復が速い）
```

---

### Step 2：APTES修飾

```
ガラス版と同条件（APTES 2%、EtOH:H₂O = 95:5、200 µL、10分浸漬）
→ EtOH 200 µL × 3回洗浄
→ N₂乾燥
→ 110°C 1時間キュア
```

> ⚠️ プラズマ処理からAPTES浸漬まで5分以内に実施

---

### ガラス版との比較ポイント

| 確認項目 | ガラス | COP |
|---------|--------|-----|
| プラズマ条件 | 100 W / 60秒 | 50〜100 W / 30秒（要検討） |
| APTES修飾までの時間 | 30分以内 | 5分以内 |
| 転写効率（暗視野比較） | 基準 | ガラスと比較 |

---

## 条件検討マトリクス

| パラメータ | 初回 | 振る範囲 | 根拠の質 |
|-----------|------|---------|---------|
| DNA濃度 | 1 µM | 0.1 / 1 / 10 µM | △ µCP文献からの外挿 |
| 接触時間 | 2分 | 1 / 2 / 5分 | ✕ 実験で決める |
| 荷重 | 200 g | 100 / 200 / 500 g | ✕ 実験で決める |
| APTES濃度 | 2% | 0.5 / 2 / 5% | ◎ 文献慣用値 |

## 対照実験（必須）

- APTES未修飾ガラスを同条件でコンタクト → 非特異転写量の定量
